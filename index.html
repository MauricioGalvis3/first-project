3. Códigos QR ISO/IEC 18004 + Deep Linking VERIFICABLE

Cada carnet genera un QR vectorial escaneable con cualquier celular que enlaza a ?verify=OCA-PET-XXX con firma criptográfica SHA-256.

4. Google Cloud Firestore REST + WhatsApp API INTEGRADO

Sincronización documental en la nube, consola interactiva de endpoints OpenAPI y despacho directo de alertas preventivas vía WhatsApp Oficial (wa.me).
